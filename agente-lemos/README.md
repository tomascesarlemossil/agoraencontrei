# 🧠 Agente Gestor Lemos

**Seu braço direito de gestão** — um agente que conhece todos os seus negócios e te ajuda a
organizar rotina, clientes, negócios e decisões. Projeto **separado**, do zero, sem relação
com o código do AgoraEncontrei.

> 👉 Comece lendo o **[PLANO-MESTRE.md](./PLANO-MESTRE.md)**.

## Como usar no dia a dia

Abra o Claude aqui e fale naturalmente. Exemplos:

- *"Me entreviste para preencher meu perfil."*
- *"Vamos fazer a revisão diária."* / *"Como estão as coisas essa semana?"*
- *"Novo cliente: João, quer alugar a casa da Rua X. Registra."*
- *"Apareceu um terreno de R$ 300 mil pra loteamento, vale a pena?"*
- *"Quais cobranças estão atrasadas?"*
- *"Fechamento do mês."*

O agente sabe onde guardar cada coisa e o que te perguntar.

## Mapa das pastas

| Pasta | O que é |
|-------|---------|
| `PLANO-MESTRE.md` | A bússola do projeto |
| `.claude/skills/gestor-lemos/` | A "personalidade" e as regras do agente |
| `conhecimento/00-perfil.md` | **Quem é você** (preencher primeiro) |
| `conhecimento/01..09` | Uma pasta por frente de negócio |
| `rotina/` | Rituais, agenda e tarefas |
| `clientes/` | Uma ficha por cliente |
| `negocios/` | Uma ficha por negócio/deal |
| `templates/` | Modelos para criar fichas novas |
