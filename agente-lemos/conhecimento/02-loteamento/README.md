## Fases típicas de um loteamento (checklist mestre)
1. [ ] Aquisição / opção da gleba
2. [ ] Viabilidade (topografia, ambiental, mercado)
3. [ ] Projeto urbanístico
4. [ ] Aprovação na prefeitura / órgãos (licença ambiental, etc.)
5. [ ] Registro do parcelamento no cartório
6. [ ] Infraestrutura (terraplanagem, água, energia, asfalto, drenagem)
7. [ ] Lançamento / vendas
8. [ ] Entrega e regularização final

## O que o agente precisa saber por loteamento
- Custo da terra, custo de infra, preço de venda por lote, ritmo de vendas esperado.
- Prazos de aprovação e quem são os interlocutores (prefeitura, cartório, engenheiro).
- Forma de venda (à vista, parcelado direto, financiado).
